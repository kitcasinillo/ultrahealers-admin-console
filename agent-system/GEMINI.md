## ⚡ Mandatory Bootstrap Execution Rule

Before performing any non-trivial task:

```text
1. Load Required Context  ➜  2. Review Applicable Rules/Lessons  ➜  3. Load Module Docs
           ↓
4. Generate Plan          ➜  5. Implement Changes               ➜  6. Verify Correctness
           ↓
7. Update Knowledge System (memory, skills, lessons, module docs, changelog)
```

---

## 🤝 Model Handoff & Continuity Principles

1. **Custodians of Institutional Memory**: As a model operating on this project, you are a custodian of its accumulated knowledge. Never overwrite historical lessons or reset learned behaviors.
2. **Reuse Established Patterns**: Do not invent new abstractions or custom components if a project pattern already exists in `patterns.md`.
3. **Continuous Compounding**: Update knowledge files after every completed task so future models inherit an even more capable repository.
